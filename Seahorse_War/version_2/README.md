# Seahorse War - San Gil Edition

## Versión 2

Esta es una adaptación del juego original **Seahorse War**.

Se conserva la mecánica principal del juego, pero se hicieron algunos cambios para darle una identidad propia:

- Se modificaron algunos sonidos.
- Se cambiaron algunos elementos gráficos.
- Se creó un nuevo elemento visual inspirado en San Gil.
- Se cambiaron algunos textos y colores.
- Se mantiene la jugabilidad original.

## Tecnologías

- HTML
- CSS
- JavaScript Vanilla
- Canvas

## Controles

- Flecha arriba: mover hacia arriba.
- Flecha abajo: mover hacia abajo.
- Espacio: disparar.

## Autor

Versión personalizada para el proyecto escolar "Made in San Gil".
