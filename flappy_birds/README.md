# FlappyBird San Gil

## Descripción

Este proyecto consiste en la adaptación de un juego 2D desarrollado únicamente con HTML, CSS y JavaScript Vanilla.

## Juego seleccionado

Flappy Bird.

## Versión 1

Corresponde al juego original descargado desde GitHub.

## Versión 2

Se realizó una personalización inspirada en San Gil y la región Guanentina.

### Cambios realizados

* El pájaro fue reemplazado por un cóndor.
* El fondo fue cambiado por un paisaje de San Gil.
* Los obstáculos fueron reemplazados por rocas.
* Se modificaron los colores.
* Se cambiaron los textos del juego al español.
* El título ahora es "Cóndor de Guanentá".

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript Vanilla

## Cómo ejecutar

1. Abrir la carpeta en Visual Studio Code.
2. Ejecutar `index.html` con Live Server.
3. Jugar desde el navegador.
